📌 LANGKAH 1: CEK FIREBASE RULES (PALING PENTING!)

Ini adalah penyebab #1 masalah sync (90% kasus).

1. Buka: https://console.firebase.google.com/
2. Pilih project: bapperida-penilaian
3. Klik menu: Realtime Database
4. Klik tab: Rules
5. Copy paste ini:

{
  "rules": {
    "penilaian": {
      ".read": true,
      ".write": true
    }
  }
}

6. Klik tombol: Publish
7. Tunggu 2 menit
8. Coba lagi!

📌 LANGKAH 3: CEK STATUS FIREBASE DI APLIKASI

Lihat header aplikasi (paling atas):

✅ BENAR: ☁️ Multi-Device Sync
❌ SALAH: 💾 Local Only

Kalau muncul "Local Only":
1. Buka file: firebase-config.js
2. Cari baris: const ENABLE_FIREBASE = 
3. Ganti jadi: const ENABLE_FIREBASE = true;
4. Save
5. Refresh browser dengan: Ctrl + Shift + R

📌 LANGKAH 4: GUNAKAN FORCE SYNC

Cara paling mudah paksa download data dari Firebase:

1. Buka halaman Dashboard (index.html)
2. Scroll ke section "Dashboard Perangkingan"
3. Klik tombol hijau: ☁️ Force Sync
4. Tunggu notifikasi "Sync berhasil"
5. Data akan muncul!

═══════════════════════════════════════════════════════════

📌 LANGKAH 5: CEK DI PERANGKAT TEMAN

Pastikan teman sudah benar-benar upload ke Firebase:

1. Minta teman buka Console (tekan F12)
2. Suruh teman klik Simpan
3. Di console harus muncul:
   
   💾 Saving data for: [nama inovasi]
   ☁️ Synced to Firebase  ← HARUS ADA INI!
   ✅ saveAll COMPLETE

4. Kalau tidak ada "Synced to Firebase" berarti:
   - Firebase tidak aktif di perangkat teman
   - Atau ada error

🔧 COMMAND MANUAL (COPY KE CONSOLE BROWSER)

Lihat file: CONSOLE_COMMANDS.txt untuk command lengkap!

Quick commands:

1. Cek semua data Firebase:
───────────────────────────────────────────────────────────
firebase.database().ref('penilaian').once('value').then(snap => {
  console.log('Data:', snap.val());
});
───────────────────────────────────────────────────────────

2. Force reload dari Firebase:
───────────────────────────────────────────────────────────
cloudStorage.loadAllDraf().then(data => {
  console.log('Total:', Object.keys(data).length);
});
───────────────────────────────────────────────────────────

3. Cek koneksi:
───────────────────────────────────────────────────────────
cloudStorage.checkConnection().then(s => console.log(s));
───────────────────────────────────────────────────────────
